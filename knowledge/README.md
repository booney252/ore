# Copywriting knowledge

Everything in this folder is loaded every time the tool writes briefs. Edit freely; it syncs through git.

Put your **own notes and summaries** here. Don't paste course material word for word (course terms usually forbid redistributing it).

| File | What goes in it |
|---|---|
| `rmbc.md` | Your RMBC notes: how you do Research, Mechanism, Brief, Copy |
| `hooks.md` | Hook patterns that work, with examples (spoken line + first frame) |
| `short-form-video.md` | What you know about UGC / Reels / TikTok structure, pacing, retention |
| `swipe-file.md` | Ads you love (yours or anyone's), with a link and one line on why they work |
| `rules.md` | Things to always / never do for PeptidePal (voice, claims, compliance) |

Add more files any time. Any `.md` file here gets loaded.
